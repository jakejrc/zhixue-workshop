🟢 方案一：Anaconda 安装（推荐）
Step 1：下载 Anaconda

访问 anaconda.com/download，下载 Windows 64-bit 版本（约 800MB）。

国内下载慢？用清华镜像：mirrors.tuna.tsinghua.edu.cn
Step 2：安装

双击安装包，一路 Next。注意：

  • ✅ 勾选 "Add Anaconda to PATH"（虽然它说不推荐，但对新手更方便）
  • ✅ 选择 "Just Me" 安装
Step 3：验证安装

打开 Anaconda Prompt（开始菜单搜索），输入：

python --version          # 应显示 Python 3.x
conda --version           # 应显示 conda 24.x
python -c "import sklearn; print(sklearn.__version__)"  # 应显示版本号
Step 4：启动 Jupyter Notebook
jupyter notebook

浏览器自动打开，新建一个 Python 3 笔记本即可开始写代码。

🔵 方案二：pip 手动安装
Step 1：确认 Python 已安装
python --version   # 需要 Python 3.8+

没有？去 python.org 下载，安装时勾选 "Add to PATH"。

Step 2：配置国内镜像（加速下载）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
Step 3：安装课程所需库
pip install numpy pandas matplotlib scikit-learn jupyter seaborn
Step 4：启动 Jupyter
jupyter notebook

常见问题

使用清华镜像源：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名

说明没装scikit-learn，运行 pip install scikit-learn。注意包名是 scikit-learn 不是 sklearn。

试试 pip install --upgrade jupyter，然后 jupyter notebook。如果还不行，用 jupyter lab 替代。

必须用 Python 3（3.8+）。Python 2 已经停止维护，sklearn 等库不再支持。

可以！安装 VSCode + Python 扩展 + Jupyter 扩展，体验更好。但课程作业默认用 Jupyter Notebook。

pandas>=1.3
matplotlib>=3.5
